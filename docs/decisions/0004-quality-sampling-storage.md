# ADR 0004: 生成品質、任意のGPU計測、問題単位の永続化

- 状態: 採用（2026-10-13 UTC）
- 対象: 実装書3.3、6.3、8、9、13、Phase 3/4/6

入力の順序が無関係であると仕様から判断できる13生成器のみ、入力の並べ替えを同値として扱う。全生成器への数値・名前の置換正規化は、答えや必要な操作を変える問題を誤って除外し得るため採用しない。テンプレートの反復と同値問題の除外を別々に記録する。既存セットは保存された実体を再利用し、新規セットに検出方式版を含める。

GPUは既存nvidia-smi診断のパーサーを共用して、約1秒間隔の任意計測を追加する。GPUなしのCPU環境に新規必須依存を導入しない。GPUごと・指標ごとの集計だけを保持し、モデル専用の使用量や連続時間上の真のPeakとは表示しない。プローブ失敗をモデルの誤答・実行失敗へ変換しない。計測プロセスの作成中・実行中のキャンセルを両方回収する。

DB v3では凍結した問題をset_itemsへ分離する。移行はSQLiteのJSON機能で行い、Pythonで全問題を展開しない。移行全体を単一トランザクションとし、元データ・ハッシュ・順序・試行を保持する。移行を失敗させる試験で旧版へのロールバックを確認する。正常移行後は旧版アプリとの互換性がないため、更新前の停止・バックアップ手順を記載する。

評価は32問の短い読取単位、アーカイブは同一スナップショット内で1問単位、Webログは50件単位。旧HTTP全詳細応答とFrozenSet APIは互換性のため維持する。freeze作成自体と明示的な全詳細応答はまだ全件分のメモリを使用する。数日規模の実モデル耐久性は別途検証が必要。

推論シードをモデル設定で明示する。旧データの既定0を維持し、問題生成用seedと区別する。GPU計測ON/OFFと推論seedの差を比較時に警告する。
