# ADR 0001: CPUで検証可能なPreviewから始める

- 日付: 2026-10-12
- 状態: 採用

空の `Lye-0/benchmark-forge` に、Python 3.12 / FastAPI / Pydantic / SQLite / TyperとReact / TypeScript / Viteを採用します。GPU依存はオプションとし、CPUとMockで縦方向の動作を確認します。UI/CLIは共通のPythonサービス層を呼び、保存後のセットをモデル間で共有します。

標準16カテゴリの分類体系に14生成器を登録。9カテゴリで独立した複数の問題構造を提供し、未実装分野はunavailableとして表示します。カテゴリ間の難易度校正、層化分布、十分な固定コーパスが未完成のため、Preview v1のみ提供し、Standard版を拒否します。

fixed_catalogue.jsonlは算法から作った280件を追跡します。ランタイムで再生成せず、参照解答を含む実体を保持。問題文の表面的重複を拒否し、構造の反復は統計に残します。正式版では大規模コーパスと校正、ホールドアウト管理へ拡張します。

初期隔離機能はfail-closedとします。コマンドやモデル生成コードを直接実行せず、ワーカーと侵入試験が揃うまで無効表示します。単にDockerがインストールされていることを能力として扱いません。
