# 0005: 校正前の観測点検と保存済みセットの再利用

2026-10-14。Phase 6の結果収集・分析を、利用者PCへの追加環境導入なしで進める。

- 集計は同じセット・採点器の完了した通常実モデル評価2〜10件に限定する。Mockや独立評価のスコアを混ぜない。
- モデル識別子/バックエンド/リビジョン/量子化が同じ再実行は拒否する。登録別名や別バックエンドによる重み同一性は検証できないため警告し、登録数を統計的な独立標本数と主張しない。
- 最終結果を問題ごと・モデルごとに1件数える。エラーやタイムアウトも分母に保持し、再試行の選択バイアスを明示する。欠測帯はN/Aとし、実測難易度への変換やIRTの推定は行わない。
- CLI出力は新規ファイル限定。モデル条件・環境情報を含むローカル成果物とし、問題本文・参照解答・モデルの生回答を含めない。
- 追加モデルの実行には保存済みset_idを直接使う。生成器版の更新後も元の問題実体を保持し、過去の結果を上書きしない。コード/ツール/速度の独立セットは通常評価の再利用UIから除外する。
- 利用者のDocker実機検証は後日に保留。確認済みのQwenを再実行せず、既存Gemmaを同じ2問で実行して機能経路を確認する。これは校正完了のデータ量ではない。
