# UI全体の操作・文言点検（2026-10-14）

## 範囲と方法

前回の部分点検を広げ、`apps/web/src` の全画面・全表示コンポーネントを対象にした。astra / medium の4エージェントが以下の分担で静的点検し、親がAPI・保存・実行処理と照合して採否判断と修正を行った。主要変更は再点検済み。

点検対象は通常・未選択・上限・未対応・処理中・成功・失敗・画面移動・再読み込みの各状態。全画面のソースと操作を対象にしたことと、全状態の実機操作を尽くしたことは区別する。Windows/Ollama/CUDA/Dockerの新たな実機試験は行っていない。

## 検証の区別

- 静的点検は上表の全範囲。採用した指摘はコードへ反映し、非同期・失敗・入力の意味が変わる修正には回帰テストを追加した。
- ブラウザ試験は100問2モデルの通常評価、詳細切替・再読み込み・中断再開・ログ・比較、390pxのナビ／キーボード・未対応カテゴリ、持ち込み問題の2モデル開始、複数ターン評価、速度試験を含む。
- 自動テストの結果は `STATUS.md` の同日追記に記録する。全ブラウザ・全OS・実機機能の完全検証、未知の不具合がないことを保証するものではない。
- 長時間処理するPOSTを一律の短いタイムアウトで打ち切る変更は採用しない。サーバー側で実行が成立している可能性があるため、重複開始を誘発する自動再送も追加しない。
