# 安全性とローカル運用

## 現在の境界

バックエンドは127.0.0.1にバインドし、HostとOriginを検証。CORSはローカルの指定Web Originに限定します。cross-siteのFetch Metadataを拒否し、変更操作はapplication/jsonと1MB以下の入力に限定。セッション認証のないローカル個人用アプリであり、インターネットや共有ネットワークに公開する構成は対象外です。

Ollama接続先はHTTPの127.0.0.1または::1のliteralに限定。DNS名、外部IP、クラウドmetadata IP、URL credentials、path/query、redirectを拒否します。localhostプロキシを避けるためhttpxのtrust_env=Falseを使用。モデルへ送るのは公開問題本文のみです。Ollamaの管理・モデル取得はユーザー側で行います。

参照解答は生成器・SQLite・固定コーパスに存在します。問題セットAPIとアダプター入力からは除外。結果画面・エクスポートは研究用に正解を表示します。ローカルOSユーザー自身からDBを秘匿する認証システムではありません。

## コード・エージェント実行

生成コード、シェルコマンド、Codexサブプロセスは実行しません。コード読解とテキストでの修正選択はデータ処理として採点。隔離ワーカーは現在未実装で `available=false` です。Dockerバイナリの存在ではこの状態を変更しません。

将来の実行機能は、rootlessの使い捨て専用ワーカー、network=none、read-only root、non-root、cap-drop、no-new-privileges、CPU/RAM/PID/出力/時間制限、秘密ディレクトリとDocker socketをマウントしない条件、および実侵入テストが必要です。Dockerを完全なセキュリティ境界とは断定しません。これらの実際の安全性テストは未実施で、現在のfail-closedテストが代わりに合格したと主張しません。

Codex CLI/App Serverはprotocol-onlyです。CLI JSONイベントの失敗・ツール実行、RPCの未認証・エラー・キャンセル・ツール承認要求をMockで拒否します。read-only sandboxだけでは正解データの読み取りを防げないため、live transportやホストプロセス起動を提供しません。ツール実行を後からイベントで検出する方式だけでも予防にはならないため、この状態で正式評価を許可しません。

公式Sign in with ChatGPTのプレビュー参加条件・登録・認証・token refreshは未確認/未実装。認証キャッシュを解析せず、ユーザーにキー入力を求めず、課金APIへ切り替えません。

## 保存・公開

- SQLite、認証情報、.env、モデル重み、巨大な出力はGit ignore。コードライセンスは未確定。
- 受け取った外部エラーbodyやURLは表示せず、安全な分類済みメッセージを返します。パッケージ/通信のTLSと署名検証を無効化しません。
- SQLはparameterized。ブラウザはReactテキストとして出力し、モデル応答のHTMLを挿入しません。
- CSVの危険な数式先頭をquoteして、表計算ソフトでの式実行を防止。
- APIには任意ファイル読込、ZIP展開、任意シェル、認証値の登録を提供していません。
- secret_scan.pyは既知トークン形式・秘密ファイル・重み/DBの公開を検査し、検出値を表示しません。すべての秘密や個人情報を検出できる保証はなく、ユーザーの回答や出力を公開する際は別途内容を確認してください。

ローカルアプリが接続するOllamaサービスや同じOSユーザー権限の悪意あるプロセスは、アプリの隔離境界の外にあります。複数利用者、外部公開、任意プラグイン、非公開holdout importを追加するときは別の脅威分析が必要です。
