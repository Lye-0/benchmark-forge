# 開発用回答診断

このディレクトリは、指示書12章のCodex Cloud sub-agentによる実回答診断だけを保存します。モデルランキング、正式ランDB、性能比較には混ぜません。

2026-10-12の初回診断は、生成器が作った数学・論理・結合・コード読解・日時計算の5問題を、会話履歴を引き継がない新しいsub-agentへ渡しました。渡したのは問題本文のみで、参照解答や生成器/採点器コードを渡していません。ツールを使わず回答するよう指示し、返された回答は通常の `grade()` で照合しました。5問とも正解でした。曖昧さ・採点器不具合はこの小標本では見つかりませんでした。

sub-agentは同じ共有ワークスペースにアクセスできるプラットフォームであり、機械的なファイル読取禁止は実施できていません。この手順をセキュリティ境界や正式性能測定として扱わないでください。診断エージェントはファイル/ツールアクセスを実施せず、回答を直接返しました。

ユーザーの追加指定「新規sub-agentはastra mid」は初回診断終了後に届いたため、初回は再実行していません。それ以降の独立実装レビューはgpt-6-astra / mediumで実施しました。
